# Brain Game (brain-game.io): A Study in Cognition

A 3D brain rendered as a Victorian woodblock engraving. Players rotate it to catch falling words on the brain region responsible for them. We are adding an AI voice guide (Sylvi or Rollo: the brain itself, speaking in the first person) and a sourced knowledge graph behind it.

## Start here

1. `docs/claude/CLAUDE_CODE_HANDOFF.md`: current state, next task, file map, decisions waiting on Kyle.
2. `docs/claude/BRAIN_GAME_PROJECT_INSTRUCTIONS.md`: the full brief (vision, aesthetic, integrity standards). Its 14-zone table is outdated: the 20 regions in `src/data/brainRegions.json` are canon.
3. `.cursorrules`
4. `docs/claude/VOICE_CONFIG_UPDATE.md`: the live ElevenLabs agent (Sylvi and Rollo, one British voice each, Rollo the default) and the decisions behind it.

## Stack and commands

React 18, Three.js r170, custom GLSL shaders, Vite 6, Vitest. Deployed on Railway.

```bash
npm run dev                     # local dev server
npx vitest run                  # all tests
npm run build
npm run kb -- validate          # knowledge base: typed errors, exit 1 on any
npm run kb -- preview           # proposed + approved -> knowledge/build/ (git-ignored)
npm run kb -- review:export     # steward review sheet
npm run kb -- review:import <csv>
npm run kb -- compile           # approved only -> src/data/brainGraph.json
```

## Canon

- `src/data/brainRegions.json` is canon for the 20 painted regions and is never edited (artist handoff). `regionGeometry.json` is generated by `scripts/generate-region-geometry.py`.
- The paint is fixed. No repainting. Names and text may change; colour regions may not.
- Regions 6 (Broca's) and 13 (Wernicke's) exist only on the anatomical left. In model space +x is anatomical left, +y superior, +z anterior.
- `knowledge/` holds the knowledge graph (authoritative for relationships) and the narrative KB (depth). When they disagree, the graph wins. Spec: `knowledge/ONTOLOGY.md`.

## Working rules (non-negotiable)

- **Research, then Plan, then Execute.** Get Kyle's explicit confirmation before writing code.
- **TDD:** write tests, run them and confirm they fail, commit the tests, then implement until they pass.
- **Existing user controls never change.** New behaviour is additive and opt-in; the voice guide acts only in Study mode, when the player engages it.
- **Every claim gets a number.** Self-check renders and outputs before presenting them.
- **Stay in scope.** Edit only what the task names. No global smoothing or cleanup passes: they break work that was already correct.
- **Neuroscience integrity:** region names are tissue nouns, never functions. No left-brain/right-brain myth. The cerebellum is not just balance. Functions are tagged primary or contributing. Sources are Kandel, Purves, Nolte or peer-reviewed work, never pop-science, Wikipedia or news. No text may copy 8 or more consecutive words from a source (a test enforces this in `knowledge/`).
- **Medical:** the guides never give medical advice. They say plainly that they are sorry but cannot, then offer to explain the anatomy.
- **Writing:** no em dashes in prose. Collaborative "we/our" with Kyle.

## Hard-won lessons

- Camera tools drive the existing orbit controller, never the camera directly. `BrainOrbitControls` rotates the specimen (`orientGroup.quaternion`), not the camera.
- A confetti or checkerboard pattern means the wrong UV channel: use `uv3` / `TEXCOORD_3` with `flipY = false`, `NoColorSpace`, `NearestFilter`, no mipmaps. It is a renderer setting, not a model fault.
- Diagnostic: a model problem shows in both offline renders and the engine; a render problem shows in only one.
- Region shape corrections go through the vector artwork, never per-view crop edits (they accumulate drift).
- `pypdfium2` renders BGR, not RGB (flip `[:, :, ::-1]` before comparing colours). Artwork must be RGB, never CMYK.
- Two camera bugs looked correct and were caught only by assertions ("cerebellum must not be visible from above", "primary visual must not appear laterally"). Keep assertions like these as regression tests.
